# Escopo atual do ShapeLab

O ShapeLab concentra-se em treino, alimentação, hidratação, sono, evolução corporal, fotos e anotações.
Agenda, tarefas e finanças foram retirados do produto nesta versão para desenvolvimento em projeto separado.

Os campos de dados legados continuam disponíveis somente para permitir recuperação de backups antigos.
Não reintroduzir interfaces desses módulos sem decisão explícita de produto.
